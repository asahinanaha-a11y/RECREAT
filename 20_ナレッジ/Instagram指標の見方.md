# Instagram指標の見方

分析・レポートで指標を扱うときの共通の物差しです。

## 何を最重要に見るか

目的によって見る指標が変わります。**1アカウントにつき最重要指標は1つ**に絞ります。

| アカウントの目的 | 最重要指標 | 補助的に見る指標 |
|---|---|---|
| 認知を広げたい | リーチ（特に非フォロワーリーチ） | シェア数 |
| 関係を深めたい | 保存数・保存率 | コメント、リピート視聴 |
| 来店・予約につなげたい | プロフィールアクセス → リンククリック | ストーリーズのリンクタップ |
| フォロワーを増やしたい | 投稿別のフォロー数 | プロフィールアクセス率 |

**いいね数は最重要指標にしない。** 表示順に影響しにくく、行動につながりにくいためです。

## 主な指標の意味

| 指標 | 意味 | 見るときの注意 |
|---|---|---|
| リーチ | 見た人の数（重複なし） | フォロワー / 非フォロワーの内訳を必ず見る |
| インプレッション | 表示された回数（重複あり） | リーチとの差が大きい＝繰り返し見られている |
| 保存 | あとで見返すために保存された回数 | 「役に立った」の指標。伸びの先行指標になりやすい |
| シェア | 他人に送られた回数 | 拡散の指標。認知目的では最重要 |
| プロフィールアクセス | 投稿からプロフィールを見た数 | 投稿が「この人は誰？」と思わせられたか |
| リンククリック | プロフィールのリンクを押した数 | 実際の行動に一番近い |
| 視聴維持率 | 動画がどこまで見られたか | 冒頭1〜3秒の離脱が最大の課題になりやすい |

## 率で見る

実数だけでは投稿数の影響を受けます。必ず率も出します。

- **保存率** ＝ 保存数 ÷ リーチ
- **プロフィールアクセス率** ＝ プロフィールアクセス ÷ リーチ
- **エンゲージメント率** ＝（いいね＋コメント＋保存＋シェア）÷ リーチ

## だいたいの目安

業種・規模で大きく変わるため、**他社の目安より自社の前月比を優先**します。
あくまで参考値：

| 指標 | 弱い | 普通 | 良い |
|---|---|---|---|
| 保存率 | 〜1% | 1〜3% | 3%〜 |
| エンゲージメント率 | 〜2% | 2〜5% | 5%〜 |
| 非フォロワーリーチ比率 | 〜30% | 30〜60% | 60%〜 |

## 判断を誤りやすい場面

- **1本のバズで平均が動く** → 中央値も見る、またはバズ投稿を除いた数字も出す
- **投稿数が減った月はリーチも減る** → 投稿1本あたりで比べる
- **フォロワーが増えた直後はリーチ率が下がる** → 実数とあわせて見る
- **リールとフィードを同じ土俵で比べない** → 形式別に比較する
- **季節要因** → 前月比と前年同月比の両方を見る（データがある場合のみ）
