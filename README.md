# RECREAT — SNS運用の第二の脳（Obsidian Vault）

このリポジトリは **Obsidian の Vault** です。
SNS運用を「ネタ → 投稿 → 数値 → 知見」の一本の流れで回すための第二の脳として作ってあります。

## 使い始める

1. Obsidian を開く
2. 「フォルダを Vault として開く」→ このリポジトリのフォルダを選択
3. `ホーム.md` が入口。まずは `使い方.md` を読む

設定（`.obsidian/`）はコミット済みなので、開いた時点でテンプレートとデイリーノートが使える状態です。
端末ごとに変わる `workspace.json` などは `.gitignore` 済み。

## フォルダ構成

```
ホーム.md            ← 入口（ダッシュボード）
使い方.md            ← 運用ルールと1日の流れ
00_Inbox/            ← ネタ・思いつきの一時置き場
10_Daily/            ← デイリーノート（YYYY-MM-DD）
20_Posts/            ← 投稿ノート（下書き→予約→公開＋数値）
  公開済み/
30_Campaigns/        ← 期限とゴールのある施策
40_Accounts/         ← アカウント別の戦略・トンマナ・KPI
50_Research/         ← 競合・トレンド・参考投稿
60_Notes/            ← 検証して残った知見（勝ちパターン）
70_Reports/          ← 週次・月次レポート
80_Archive/          ← 終わったもの
90_Templates/        ← テンプレート
99_Attachments/      ← 画像・動画素材
```

## テンプレート

`Ctrl/Cmd + P` →「テンプレートを挿入」で使えます。

| テンプレート | 用途 |
| --- | --- |
| デイリーノート | 今日出す投稿・拾ったネタ・反応チェック |
| ネタ | アイデア1つ（誰に / 何を渡す / フック案） |
| 投稿 | 投稿1本（目的・本文・公開前チェック・公開後の数値） |
| キャンペーン | 期限つき施策（ゴール・KPI・投稿計画） |
| アカウント | 運用アカウントの戦略・トンマナ・投稿ルール |
| リサーチ | 競合投稿・トレンドの分析 |
| 知見 | 「〜すると〜になる」の言い切り＋根拠 |
| 週次レポート | 数値の前週比・TOP3・来週の打ち手 |

## 運用サイクル

```
① 拾う → ② 育てる → ③ 書く → ④ 出す → ⑤ 数える → ⑥ 知見にする
```

詳細は `使い方.md`。週次30分・月次60分のルーティンもそこに書いてあります。

## 補足：使っているプラグイン

コアプラグインのみで動きます（デイリーノート / テンプレート / バックリンク / プロパティ / グラフ / ブックマーク）。
投稿の一覧を自動生成したい場合はコミュニティプラグインの **Dataview** を追加すると便利です（`ホーム.md` にコメントアウトしたクエリ例あり）。

## 補足：請求書関連のファイルについて

`請求書/`・`支払い請求書/`・`organize_invoices.py` は以前の用途（請求書の月別整理）で作られたものです。
今回のSNS運用用途とは無関係なので、不要であれば削除してください。
