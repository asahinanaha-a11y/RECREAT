# RECREAT — Instagram運用チーム（Obsidian × Claude Code）

Instagram運用代行の月次業務を、Obsidian保管庫とClaude Codeのエージェントチームで回すための一式です。

```
人がデータを置く → /monthly を実行 → 分析・広告・競合・企画・デザイン・レポート・送付一式ができる → 人が確認して送る
```

## はじめて使うとき

- [`はじめかた.md`](はじめかた.md) — 短い版（操作に慣れている方向け）
- [`初心者向けセットアップ手順.md`](初心者向けセットアップ手順.md) — 画面ごとに説明した版
- [`ホーム.md`](ホーム.md) — Obsidianで開いたときの入口

Obsidianで「フォルダを保管庫として開く」→ このフォルダを選択。
ターミナルで同じフォルダに移動して `claude` を起動すれば準備完了です。

## チーム（7体）

| エージェント | 役割 | 作るもの |
|---|---|---|
| `production-director` | 全体の段取り・品質確認 | 送付一式 |
| `instagram-analyst` | インサイト分析 | `分析/YYYY-MM_分析.md` |
| `ad-operator` | 広告の実績と改善案 | `広告/YYYY-MM_広告.md` |
| `competitor-researcher` | 競合リサーチと転用案 | `リサーチ/YYYY-MM_競合.md` |
| `content-planner` | 翌月の投稿企画 | `企画/YYYY-MM_企画.md` |
| `design-director` | 制作指示書 | `デザイン/YYYY-MM_デザイン.md` |
| `report-writer` | クライアント提出用レポート | `レポート/YYYY-MM_レポート.md` |

定義は `.claude/agents/` にあります。動きを変えたいときは、そのファイルを直すか、
Claude Codeに「〇〇エージェントをこう直して」と伝えてください。

## コマンド

```
claude --agent production-director

/monthly 焼肉店A 2026-09     月次サイクルを丸ごと回す
/clear                       次の会社に移る前に必ず実行
```

`/monthly` の中身は `.claude/skills/monthly/SKILL.md` に書かれています。
途中で止まっても、同じコマンドをもう一度実行すれば管理表を見て続きから再開します。

## フォルダ構成

```
CLAUDE.md                共通の就業ルール（全エージェントが従う）
ホーム.md / はじめかた.md / 初心者向けセットアップ手順.md

05_月次管理/YYYY-MM.md    全社の進捗表
10_クライアント/<名前>/
  基本情報.md            すべての起点。ここが薄いと成果物も薄くなる
  効いた型.md            そのアカウントで実際に伸びた型
  データ/                人が置くCSV（gitignore済み）
  分析/ 広告/ リサーチ/ 企画/ デザイン/ レポート/ 送付/
20_ナレッジ/              全社横断の知見・指標の見方・表現の注意点
90_テンプレート/           各成果物のひな形
99_添付/                  画像などの添付ファイル
```

## 設計上の約束

- **数値を作らない。** データにない数値は書かず「データなし」と書く
- **1会話1クライアント。** 混線を防ぐため、会社を変えるときは `/clear`
- **送信はしない。** エージェントが作るのは提出前の原稿まで。送るのは人
- **事実と解釈を分ける。** 仮説は「〜と考えられます」と書き、断定しない

## データについて

`10_クライアント/*/データ/` はgitignoreしています。
クライアントのインサイトCSVや広告データには個人情報・実売上が含まれるため、
リポジトリには入れず、各自のパソコンにだけ置いてください。
