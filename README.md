# 請求書管理

請求書を月別に整理・管理するためのリポジトリです。

## フォルダ構成

```
請求書/          ← 売上・受領した請求書
  2026/
    01月/
    02月/
    ...
支払い請求書/    ← 支払い用の請求書
  2026/
    01月/
    02月/
    ...
```

## 自動振り分けスクリプト

請求書ファイルが入ったフォルダを指定すると、ファイル名や日付から自動で月別フォルダに振り分けます。

```bash
python organize_invoices.py <請求書フォルダのパス>
```

### 振り分けルール

- ファイル名に「支払」が含まれる → `支払い請求書/` へ
- それ以外 → `請求書/` へ
- 年月はファイル名から自動検出（例: `請求書_2026-04.pdf`）、検出できなければファイル更新日を使用
- 対応拡張子: PDF, Excel, CSV, Word, 画像ファイル
